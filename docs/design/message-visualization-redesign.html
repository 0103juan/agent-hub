Ficha Técnica y Criterios Gráficos Aplicados

Tipografía y Ritmo

Se mantuvieron dos familias tipográficas: Inter / System para texto explicativo (13px, leading-6) y JetBrains Mono / Consolas para nombres de archivo y líneas (11.5px y 10px). El interletrado y la sangría de listas alinean a una retícula de 8px.

Paleta Cromática

Color dominante: Zinc 950 y 900. Apoyo: Zinc 800 y 700 para contenedores interactivos. Acentos semánticos: Sky para docs, Emerald para código, Amber para configuraciones e Índigo para rangos de línea y foco.

Contraste y Ergonomía

Texto principal (#e4e4e7 sobre #09090b) con ratio de contraste 12.8:1. Badges (#a5b4fc sobre #1e1b4b) con ratio 6.2:1, superando ampliamente el estándar WCAG AA de 4.5:1.
